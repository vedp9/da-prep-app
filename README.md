# DA Prep App

A mobile-first web application that helps aspiring data analysts prepare for interviews through structured, easy-to-access practice content.

🔗 **Live Demo:** [da-prep-app.vercel.app](https://da-prep-app.vercel.app/)  
💻 **Repository:** [github.com/vedp9/da-prep-app](https://github.com/vedp9/da-prep-app)

## Overview

DA Prep App is designed as a focused interview-preparation companion for data analyst candidates. It provides an organized and responsive learning experience that makes it easier to review key topics and practice interview readiness from any device.

## Features

- Mobile-first and responsive user interface
- Structured content for data analyst interview preparation
- Clean, distraction-free learning experience
- Fast client-side application built with Vite
- Deployed for public access through Vercel

## Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS and CSS
- **Language:** JavaScript
- **Deployment:** Vercel

## Getting Started

### Prerequisites

Install the following before running the project locally:

- Node.js 18 or later
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/vedp9/da-prep-app.git
```

2. Navigate to the project directory:

```bash
cd da-prep-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## Available Scripts

```bash
npm run dev       # Start the local development server
npm run build     # Create a production build
npm run preview   # Preview the production build locally
```
